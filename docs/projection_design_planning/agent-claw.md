# AgentClaw — 个人知识理解引擎

> 设计日期: 2026-05-22
> 状态: 设计草案

## 核心理念

**AI 知识管理行业优化的是"检索"（Retrieval）。AgentClaw 优化的是"理解"（Comprehension）。**

AgentClaw 不是笔记工具，不是搜索引擎。它是一个 **个人 AI 理解引擎** —— 结合 AI 驱动的网络研究、结构化知识管理、和一个随着你的理解深度而成长的领域专家助手。

## 技术栈

| 层级 | 技术 | 选择理由 |
|------|------|---------|
| GUI | Electron + Next.js 15 (Turbopack) | Forge 项目验证过的架构，跨平台 |
| Agent 核心 | pi-mono SDK | 模型自由、树状会话、五层技能系统 |
| 主力模型 | Claude (通过 pi-mono) | 最佳推理质量，用于领域分析 |
| 经济模型 | Qwen-3.5-Flash (通过 pi-mono) | 便宜，用于日常研究和分类 |
| 本地数据库 | SQLite (better-sqlite3, WAL) | 简单快速，Forge 验证 |
| 向量搜索 | SQLite-vss 或 Qdrant (本地) | 混合搜索 (dense + BM25) |
| 知识图谱 | 基于 SQLite 自建 | 领域本体、关系、时间线 |
| 嵌入模型 | text-embedding-3-large | 基准质量的混合搜索 |

## 八大功能规格

### F1: GUI 界面
- Electron + Next.js 15 前端
- 侧边栏：领域导航树
- 主区域：上下文相关（领域视图、专家对话、时间线、研究仪表盘）
- 暗色/亮色主题
- 本地优先：所有数据在磁盘，不依赖云

### F2: 定时每日网络研究
- pi-mono 代理按时运行（每领域可配置）
- 使用廉价模型节省成本
- 搜索预配置的领域来源
- 自动将发现导入知识图谱，带来源追踪
- 仪表盘显示每日研究摘要

### F3: 领域内容摘要与框架分析
- 领域专家代理生成结构化摘要
- 应用分析框架（按领域可配置）：
  - 技术领域：技术成熟度、竞争格局
  - 商业领域：波特五力、SWOT
  - 学术领域：文献综述方法论
- 框架判断作为知识图谱节点存储

### F4: 领域发展时间线与预测
- 按领域的时间线知识图谱遍历
- AI 生成的趋势分析和未来预测
- 可视化时间线组件
- 预测置信度评分
- 历史准确率追踪

### F5: 双模式知识录入
- **主动模式**：用户直接编写（Markdown 编辑器）
- **被动模式**：用户提供主题/查询 → 代理研究 → 摘要 → 存储
- 两种模式都汇入同一知识图谱
- 主动条目获得 AI 建议的知识连接

### F6: 领域分类与独立逻辑线
- 每个领域拥有独立的：
  - 知识图谱子图
  - 专家代理人设/提示词
  - 研究来源和计划
  - 分析框架
  - 技能配置
- 领域可有父子关系
- 代理自动发现跨领域连接

### F7: 自进化技能系统
- 基于 pi-mono 五层扩展系统：
  - Extensions：TypeScript 模块自定义工具行为
  - Skills：SKILL.md 文件教授代理领域特定工作流
  - Prompt Templates：每领域可复用的提示词模式
  - Themes：每领域的视觉定制
  - Pi Packages：可分享的技能包
- 技能可以是全局的或领域特定的
- 基于使用模式和用户反馈进化

### F8: 外部内容导入
- 支持来源：知乎、博客、PDF、网页、RSS
- 导入管道：获取 → 提取文本 → AI 摘要 → 提取引用 → 存入知识图谱
- 来源追踪：每个导入的事实链接回其来源
- 与已有知识去重

## 构建顺序

## 关键技术决策

### 为什么选 pi-mono 而不是 Claude Agent SDK
1. **模型自由**：日研究成本 $0.50 vs $5-15
2. **树状会话**：知识探索的自然映射
3. **五层技能系统**：唯一匹配 F7 的 SDK
4. **无供应商锁定**：通过 pi-mono 使用 Claude 模型
5. **开源 SDK 上的开源工具**

### 为什么选 Electron + Next.js
1. Forge 项目验证了相同架构
2. Next.js 15 + Turbopack = 快速开发 + 快速 HMR
3. 丰富的 React 生态（时间线、图可视化、Markdown 编辑器）
4. 跨平台（macOS、Windows、Linux）
