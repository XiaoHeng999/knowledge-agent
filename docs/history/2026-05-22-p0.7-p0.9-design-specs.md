# P0.7 - P0.9 设计规格补全

> 日期: 2026-05-22
> 类型: Phase 0 设计规格

## 目标

完成 AgentClaw 实施计划中 Phase 0 的 P0.7（日志与可观测性）、P0.8（安全关卡规格）、P0.9（动画预设系统）共 9 项设计规格任务。

## 实现摘要

### P0.7 日志与可观测性（3 项任务）

**产出文件**: `openspec/changes/agentclaw-implementation/specs/error-recovery/logging-observability.md`

- **P0.7.1 结构化日志格式**: 定义了 JSON 格式日志条目，包含必填字段（timestamp, level, module, action, message）和可选字段（traceId, duration, cost, error, context）。标准化了 19 个模块名称。定义了日志轮转策略（10MB × 5 文件 = 50MB）。引入 traceId 用于操作链路追踪。
- **P0.7.2 操作成本追踪**: 定义了 CostRecord 类型，按请求记录 API 调用成本（model, provider, inputTokens, outputTokens, estimatedCostUsd）。设计了静态价格表覆盖主流模型（Anthropic/OpenAI/DeepSeek/Google/Ollama）。定义了 5 个成本聚合 API（session/domain/model/daily/operations）。
- **P0.7.3 调试模式**: 支持 4 种激活方式（设置 UI / 快捷键 Cmd+Shift+D / 环境变量 / CLI 参数）。调试模式启用后：日志级别降至 debug、记录所有 IPC 调用、Worker 全生命周期日志、性能指标采集面板。设计浮动调试面板展示内存/Worker/DB/IPC/Token 指标。

### P0.8 安全关卡规格（3 项任务）

**产出文件**: `openspec/changes/agentclaw-implementation/specs/version-control/security-gates.md`

- **P0.8.1 自动化写入审核关卡**: 定义了 Agent 写入操作的风险评估流程，包含 12 种操作的审计分类。风险评估规则涵盖路径边界检查、文件类型检查、内容变更大小、删除操作、批量操作。通过 SecurityGate 服务在 IPC 边界强制执行。
- **P0.8.2 Diff 审核排队机制**: 设计了右侧面板堆栈排队 UI，按风险等级排序（HIGH→MEDIUM→LOW）。设计了聊天输入区域的 "N pending reviews" 徽标。按风险等级定义了不同的操作按钮（LOW 直接批准、MEDIUM 单击确认、HIGH 需输入 "APPROVE"）。LOW 风险操作 60 秒后自动批准。
- **P0.8.3 写入权限分级**: 定义了 4 级权限：LOW（自动通过）、MEDIUM（需确认）、HIGH（需明确批准）、BLOCKED（永远拒绝）。详细列出了每个级别的操作场景。支持用户在设置中按操作类型调整权限等级。定义了审计追踪日志。

### P0.9 动画预设系统（3 项任务）

**产出文件**: `openspec/changes/agentclaw-implementation/specs/design-specs/animation-presets.md`

- **P0.9.1 标准动画预设**: 定义了 8 个核心预设（fadeIn, fadeOut, slideUp, slideDown, scaleIn, collapse, expand, bounce）+ 4 个工具预设（skeletonPulse, toastEnter, toastExit, spin）。
- **P0.9.2 精确参数**: 为每个预设定了精确的持续时间（150ms-500ms）、缓动函数（ease-out, ease-in, ease-in-out, cubic-bezier）、起始/结束状态、CSS @keyframes 定义和 JS API 签名。
- **P0.9.3 prefers-reduced-motion 降级**: 定义了全局 CSS override 规则（所有动画 0.01ms）。为每个预设定了具体的降级行为（即时状态变化）。提供了 `useReducedMotion` React Hook 和 `createAnimator` 工厂函数。聊天自动滚动降级为 "N new messages" 指示器。
