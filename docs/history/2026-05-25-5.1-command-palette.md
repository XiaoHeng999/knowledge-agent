# 5.1 命令面板（Cmd+K）实现记录

> 日期: 2026-05-25
> 任务: 5.1.1–5.1.5 命令面板功能
> Phase: 5

## 目标

实现 AgentClaw 的全局命令面板，支持 Cmd/Ctrl+K 快速搜索命令、导航、知识和操作。

## 实现摘要

### 新增文件

- `src/components/cmd-palette/types.ts` — 类型定义（PaletteMode, ResultGroup, FuzzyMatch, ParameterState 等）
- `src/components/cmd-palette/search.ts` — 模糊匹配算法（exact > prefix > word-boundary > fuzzy）
- `src/components/cmd-palette/empty-state.tsx` — 无搜索结果空状态
- `src/components/cmd-palette/result-item.tsx` — 单个结果项组件 + ShowMore 组件
- `src/components/cmd-palette/result-group.tsx` — 分组结果组件（header + items + overflow）
- `src/components/cmd-palette/result-list.tsx` — 结果列表容器
- `src/components/cmd-palette/parameter-input.tsx` — 参数输入模式（多参数顺序收集 + 验证 + 自动补全）
- `src/components/cmd-palette/cmd-palette.tsx` — 主命令面板组件

### 修改文件

- `src/app/(main)/layout.tsx` — 集成 CommandPalette 组件
- `src/app/globals.css` — 添加命令面板样式（overlay、input、results、parameter mode）
- `docs/file-map.md` — 更新文件索引

### 功能实现

1. **5.1.1 命令面板组件**: 搜索框 + 5 个分组（Recent/Commands/Navigation/Knowledge/Actions）
2. **5.1.2 键盘交互**: ↑↓ 导航、Tab 切换分组、Enter 执行、Escape 关闭、Home/End 跳转
3. **5.1.3 搜索过滤**: 模糊匹配算法、分组结果、每组最多 5 项 + "Show N more" 溢出
4. **5.1.4 参数输入模式**: 参数化命令 → 替换搜索为参数提示、Tab 自动补全、验证、多参数顺序收集
5. **5.1.5 焦点陷阱**: 打开时焦点移入面板、aria-modal、关闭后焦点返回触发元素
