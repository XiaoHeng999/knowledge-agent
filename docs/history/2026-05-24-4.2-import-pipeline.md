# 4.2 导入管道（F8）— 实现记录

## 元数据

- **日期**: 2026-05-24
- **阶段**: Phase 4 — 高级 Agent 功能
- **功能编号**: F8（导入管道）
- **关联任务**: 4.2.1 ~ 4.2.7（OpenSpec tasks #188 ~ #194）

## 目标

实现完整的导入管道，支持 URL、PDF、RSS 三种内容来源的导入，包含内容提取、AI 摘要生成、来源追踪、收件箱暂存，以及失败重试机制。

### 技术决策

1. **URL 提取**: 使用 `@mozilla/readability` + `jsdom` 提取可读内容，`turndown` 转 Markdown
2. **PDF 提取**: 使用 `pdf-parse` 抽取文本，自动检测扫描件并提示
3. **RSS 解析**: 使用 `fast-xml-parser` 解析 RSS/Atom feed，支持两种格式
4. **异步管道**: 导入操作创建记录后立即返回，后台异步执行提取→摘要→入库
5. **失败处理**: 支持 `retry`（重新执行整个管道）和 `cancel`（中止进行中的导入）
6. **来源追踪**: 每条导入记录保留 SHA-256 内容哈希、原始 URL/文件路径、提取方法

### 管道流程

```
URL/PDF/RSS → 提取内容 → 生成摘要 → 暂存 Inbox → (可选) 自动创建知识节点
     ↓              ↓           ↓
  创建 Import    更新 status   写入 inbox_items
   记录(pending)  (processing)  (pending)
```
