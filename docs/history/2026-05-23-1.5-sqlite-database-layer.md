## 实现摘要

### 文件结构

```
server/db/
├── schema.ts                    # 15 张表的 TypeScript 类型定义 + 表名常量
├── connection.ts                # 单例连接管理（WAL 模式、自动创建目录）
├── index.ts                     # 数据库门面层（统一初始化 + 所有 Repository 实例）
├── vector.ts                    # SQLite-vec 向量搜索 + FTS5 全文搜索 + RRF 混合排序
├── migrations/
│   ├── types.ts                 # Migration 接口定义
│   ├── runner.ts                # 迁移运行器（版本追踪、验证、回滚）
│   ├── 001_initial_schema.ts    # 初始 Schema（15 表 + FTS5 + 触发器 + 默认设置）
│   └── index.ts                 # 迁移加载器
└── repositories/
    ├── base.ts                  # 泛型 CRUD 基类（create/findById/update/delete/list）
    ├── domains.ts               # 领域 Repository
    ├── knowledge-nodes.ts       # 知识节点 Repository（按领域筛选、计数）
    ├── knowledge-edges.ts       # 知识边 Repository（按节点查询、批量删除）
    ├── sources.ts               # 来源 Repository（状态统计）
    ├── timeline-entries.ts      # 时间线条目 Repository（过期预测查询）
    ├── model-configs.ts         # 模型配置 Repository（按 Provider 查询）
    ├── api-keys.ts              # API 密钥 Repository（AES-256-GCM 加密存储）
    ├── inbox.ts                 # 收件箱 Repository（状态筛选、处理、统计）
    └── decision-records.ts      # 决策记录 Repository（自动编号）
```

### 关键设计决策

1. **连接管理**: 单例模式，WAL 模式支持并发读写，`busy_timeout = 5000ms` 避免锁等待
2. **迁移系统**: 顺序版本号 + `schema_migrations` 追踪表 + 每个迁移独立事务 + 新库批量模式
3. **Repository 基类**: 泛型 `<T extends object>`，自动生成 UUID + 时间戳，prepared statement 防注入
4. **向量搜索**: SQLite-vec `vss0` 虚拟表 + FTS5 全文搜索 + RRF 倒数排名融合
5. **加密**: AES-256-GCM 加密 API Key，通过 `AGENTCLAW_ENCRYPTION_KEY` 环境变量可自定义

### IPC 集成

- `db:initialize` — 初始化连接并运行迁移
- `db:migrate` — 手动触发迁移
- `db:getVersion` — 查询当前 Schema 版本
- `db:backup` — 备份数据库文件

### 数据库初始化流程

`electron/main.ts` → `initializeDatabase()` → 创建连接 → 运行迁移 → 实例化所有 Repository → 供 IPC handler 使用
