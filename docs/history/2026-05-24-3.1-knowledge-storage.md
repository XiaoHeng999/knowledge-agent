# 3.1 知识存储基础 — 实现记录

> 日期: 2026-05-24
> 任务: Phase 3.1 — 知识存储基础 (Tasks 140–146)

## 目标

实现知识库的完整基础功能：后端知识图谱服务、IPC 通信链路、前端知识列表视图及组件。

## 实现摘要

### 后端服务

1. **KnowledgeGraph 服务** (`server/services/knowledge-graph.ts`)
   - 节点 CRUD：createNode, updateNode, deleteNode, getNode, listNodes
   - 边 CRUD：createEdge, deleteEdge（含重复检查和级联删除）
   - 图遍历：getGraph（获取域内全部节点+边）
   - 搜索：searchNodes（文本搜索，向量搜索待 3.5 实现）
   - 统计：getStats（按类型/状态分组、平均理解度）

2. **Knowledge IPC Handler** (`server/ipc/handlers/knowledge-handler.ts`)
   - 注册全部 9 个 KNOWLEDGE_CHANNELS 到 IPC
   - 集成到 `server/ipc/register.ts`

### 前端组件

3. **知识列表视图** (`src/app/(main)/domain/[id]/page.tsx`)
   - 域内知识节点列表 + 搜索 + 类型筛选 + 分页
   - 右侧面板注入式知识详情展示
   - 空状态、骨架屏加载

4. **知识节点卡片** (`src/components/knowledge/knowledge-card.tsx`)
   - 标题 + 类型标签 + 理解指示器 + 域色点 + 来源数

5. **知识详情面板** (`src/components/knowledge/knowledge-detail.tsx`)
   - 标题 + 类型 + Markdown 内容 + 相关节点 + 来源 + 操作按钮

6. **知识创建/编辑表单** (`src/components/knowledge/knowledge-form.tsx`)
   - 标题、类型选择、Markdown 内容、来源管理

7. **理解度指示器** (`src/components/knowledge/comprehension-indicator.tsx`)
   - 0-5 圆点 + `role="meter"` + aria-label

### 状态管理

- `src/stores/knowledge-store.ts` — Zustand store，管理节点/边列表、分页、筛选、选中状态

### 布局扩展

- `layout-context.tsx` 新增 `panelContent` / `setPanelContent`，支持面板内容注入
- `detail-panel.tsx` 渲染注入内容
