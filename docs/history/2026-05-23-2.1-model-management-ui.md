# 2.1 模型管理 UI（F9）— 实现记录

**日期**: 2026-05-23
**阶段**: Phase 2 — 基础功能层
**任务**: 2.1.1 ~ 2.1.7（共 7 个子任务）

## 目标

实现 AgentClaw 的模型管理系统，包括 API Key 导入与加密存储、模型发现与列表展示、运行时模型切换、领域默认模型配置。

## 实现摘要

### 后端服务层

| 文件 | 说明 |
|------|------|
| `server/pi-mono/instance.ts` | PiMonoWrapper 单例管理器，提供 `initializePiMono()` / `getPiMonoWrapper()` / `shutdownPiMono()` |
| `server/services/model-manager.ts` | ModelManager 服务，协调 pi-mono 认证与本地 DB 持久化 |
| `server/ipc/handlers/model-handler.ts` | 7 个 IPC Handler（listProviders, listModels, addApiKey, validateApiKey, removeApiKey, setDefault, getDefault） |

**关键设计决策**:
- API Key 同时存储在 pi-mono auth（运行时）和本地 SQLite（加密备份）
- 模型默认配置使用 `settings` 表的 key-value 存储，key 格式为 `global:defaultModel` 或 `domain:{id}:defaultModel:{role}`
- PiMonoCore 初始化包裹在 try-catch 中，初始化失败时应用仍可启动

### 前端 UI 层

| 文件 | 说明 |
|------|------|
| `src/stores/model-store.ts` | Zustand store，管理 providers/models/default 状态，异步调用 `window.api.model.*` |
| `src/app/(main)/settings/models/page.tsx` | 模型管理设置页，含 API Key 管理表格 + 模型列表 |
| `src/components/settings/api-key-dialog.tsx` | API Key 导入对话框（Provider 选择 + Key 输入 + 验证） |
| `src/components/settings/model-list.tsx` | 模型列表表格（搜索 + Provider 筛选 + 状态指示器 + 成本显示） |
| `src/components/chat/model-switcher.tsx` | 对话中模型切换下拉（搜索 + 当前模型高亮 + 成本提示） |
| `src/components/settings/domain-model-config.tsx` | 领域默认模型配置（按 expert/research/summary 角色配置） |

- `ModelInfo` 新增 `available: boolean` 和 `contextWindow: number` 字段
