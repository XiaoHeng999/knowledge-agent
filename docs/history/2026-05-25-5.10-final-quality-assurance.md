# 5.10 最终质量保障

> 日期: 2026-05-25
> 阶段: Phase 5 — 打磨与发布
> 任务: 5.10.1 ~ 5.10.6

## 目标

对 AgentClaw 进行全面的质量保障审计和修复，包括端到端流程验证、无障碍审计、主题一致性测试、错误场景测试、用户文档编写和开源准备。

## 实现摘要

### 5.10.1 端到端流程测试

- 审计所有 IPC Handler 注册 — 发现 `registerSettingsHandlers()` 为空壳函数
- 审计所有页面路由与 Store 连接 — 确认所有页面正确使用对应 Store 和 IPC Hook
- **修复**: 实现完整的 Settings IPC Handler（get/set/getTheme/setTheme），使用 SQLite settings 表
- **修复**: Domain Chat 页面路由 — 改用 `use(params)` 读取动态路由参数，而非 searchParams
- **修复**: DomainList 侧边栏点击 — 添加 `router.push('/domain?id=...')` 实现导航
- **修复**: Dashboard 领域卡片路由 — 统一使用查询参数模式 `/domain?id=xxx`
- **修复**: 添加 `src/app/global-error.tsx` — 全局错误边界
- **新增**: 侧边栏添加 Inbox 和 Timeline 导航链接
- 修复 TypeScript 错误: domain-handler.ts (slug → config_path), skill-engine.ts (类型比较)

### 5.10.2 无障碍审计

- 审计 ARIA 属性: button, dialog, dropdown, cmd-palette, force-graph, comprehension-indicator
- 确认焦点管理: useFocusTrap, useFocusTransfer, useRouteFocus 均正确使用
- 确认键盘导航: 侧边栏、命令面板完整键盘支持
- 确认 prefers-reduced-motion: 全局 CSS 覆盖 + 组件级别检查
- 修复 `--text-tertiary` 颜色对比度 — 所有 5 个主题提升至接近 WCAG AA

### 5.10.3 四种风格全流程测试

- 审计 4 个主题 CSS 文件的 Token 完整性
- **修复**: Notion 主题 accent 颜色不一致 — CSS 和元数据统一为 `#2eaadc`（后改为 `#1e8ab8`）
- **修复**: PostHog 主题 `--font-size-lg` 从 17px 改为 18px
- **修复**: tokens.css 注释从 "33 tokens" 更新为 "42 tokens"

### 5.10.4 错误场景测试

- 审计错误注册表、恢复策略、错误边界
- 确认 TOP 5 错误场景均有对应的注册条目和恢复路径
- 识别结构性差距: 服务端 catch 块未引用错误注册表代码、错误 Store 与 Toast 系统未桥接

### 5.10.5 用户文档

- 编写完整的 `README.md` — 包含功能介绍、技术栈、快速开始、项目结构、配置说明、架构说明、FAQ

### 5.10.6 开源准备

- 创建 `LICENSE` — MIT 协议
- 创建 `CONTRIBUTING.md` — 开发指南、代码风格、PR 规范
