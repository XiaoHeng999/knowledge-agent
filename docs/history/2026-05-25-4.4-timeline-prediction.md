# 4.4 时间线与预测（F4）— 实现记录

> 日期: 2025-05-25
> 任务: Phase 4.4 — Timeline & Prediction (F4)
> 提交: `feat: implement timeline & prediction engine (4.4 — F4)`

## 目标

实现时间线与预测功能（F4），包括时间线 CRUD、趋势分析、预测生成、准确率追踪和可视化界面。

## 实现摘要

### 新增文件

| 文件 | 职责 |
|---|---|
| `server/services/timeline-engine.ts` | 核心引擎：预测 CRUD、事件提取、趋势分析、AI 预测生成、准确率追踪、过期自动标记 |
| `server/ipc/handlers/timeline-handler.ts` | 11 个 IPC 通道处理 |
| `src/stores/timeline-store.ts` | Zustand 状态管理 |
| `src/app/(main)/timeline/page.tsx` | 时间线页面：三标签（Timeline/Predictions/Trends）、筛选、创建预测表单 |
| `src/components/timeline/timeline-event-card.tsx` | 组件：事件卡片、预测卡片、置信度条、状态徽标、准确率面板、趋势分析卡片、创建表单 |

### 修改文件

| 文件 | 变更 |
|---|---|
| `src/lib/ipc/channels.ts` | 新增 `TIMELINE_CHANNELS`（11 通道）、类型定义、`IpcChannelMap` 条目 |
| `electron/preload.ts` | 新增 `timeline` 桥接段 |
| `electron/main.ts` | 导入并调用 `initializeTimelineExecutor()` |
| `server/ipc/register.ts` | 注册 timeline handlers |
| `server/ipc/handler.ts` | `unregisterAll()` 添加 timeline 通道 |
| `docs/file-map.md` | 同步文件结构变更 |

### 关键设计决策

- 预测使用现有 `predictions` 表和 `TimelineEntriesRepository`
- 时间线事件从知识节点自动提取（event/decision 类型）+ 预测混合展示
- AI 预测使用结构化格式 `PREDICT: ... | CONFIDENCE: ... | DATE: ...` 确保可靠解析
- 趋势分析自动创建建议预测并入库
- `timeline_analyze` pi-mono 工具的 executor 已通过 `initializeTimelineExecutor()` 接入
