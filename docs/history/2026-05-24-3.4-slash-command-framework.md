# 3.4 斜杠命令框架

> 任务来源：agentclaw-implementation — Phase 3.4

## 目标

实现斜杠命令框架，支持在专家对话输入框中通过 `/command [args]` 触发预定义 Agent 工作流。

## 实现摘要

### 3.4.1 命令解析器
- 文件：`src/lib/commands/parser.ts`
- 识别 `/command [args]` 格式，提取命令名和参数
- 提供 `isCommandInput` 和 `extractPartialCommand` 辅助函数用于自动补全

### 3.4.2 命令注册表
- 文件：`src/lib/commands/registry.ts`
- 支持命令注册、按名称/前缀查找、执行路由
- 参数校验（必填参数缺失时返回错误）

### 3.4.3 内置命令
- 文件：`src/lib/commands/builtins.ts`
- 10 个内置命令：`/daily`, `/deep-dive`, `/summarize`, `/timeline`, `/framework`, `/connect`, `/predict`, `/skill`, `/review`, `/import`
- 每个命令生成结构化的 Agent prompt，引导 Agent 执行特定分析工作流

### 3.4.4 命令自动补全
- 文件：`src/components/chat/command-autocomplete.tsx`
- 输入 `/` 后弹出命令列表，支持模糊匹配、键盘导航（上下箭头/Tab/Enter/Esc）
- 选中命令后自动填入参数模板

### 集成改动
- `src/components/chat/message-input.tsx` — 接入命令解析与自动补全
- `src/app/(main)/domain/[id]/chat/page.tsx` — 传递 domainId/conversationId/modelId 到 MessageInput
- `src/app/globals.css` — 添加自动补全弹窗样式
