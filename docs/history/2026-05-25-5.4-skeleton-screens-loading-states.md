# 5.4 骨架屏与加载状态

> **日期**: 2026-05-25
> **Phase**: 5 (打磨与发布)
> **任务编号**: 5.4.1–5.4.4

## 目标

为所有 9 个主视图实现完整的骨架屏加载体验，包括闪烁阈值控制、超时状态处理和首次启动动画。

## 实现摘要

### 5.4.1 — 9 个视图骨架屏组件

**文件**: `src/components/skeleton/view-skeletons.tsx`

实现了 9 个视图级骨架屏容器，每个都准确反映真实视图结构：

| 视图 | 组件 | 骨架元素数 |
|------|------|-----------|
| 仪表盘 | `DashboardSkeleton` | ~25 |
| 知识列表 | `KnowledgeListSkeleton` | ~40 |
| 时间线 | `TimelineSkeleton` | ~25 |
| 研究仪表盘 | `ResearchDashboardSkeleton` | ~35 |
| 专家对话 | `ExpertChatSkeleton` | ~25 |
| 收件箱 | `InboxSkeleton` | ~55 |
| 领域概览 | `DomainOverviewSkeleton` | ~12 + 知识列表 |
| 知识图谱 | `KnowledgeGraphSkeleton` | ~30 |
| 设置 | `SettingsSkeleton` | ~40 |

骨架屏基元组件升级（`src/components/ui/skeleton.tsx`）：
- `Skeleton`, `SkeletonCircle`, `SkeletonLine`, `SkeletonHeading`, `SkeletonCard`, `SkeletonPill`, `SkeletonMetric`
- 布局辅助：`SkeletonRow`, `SkeletonSection`, `SkeletonLines`

### 5.4.2 — 闪烁阈值控制

**文件**: `src/lib/hooks/use-skeleton.ts`

`useLoadingState` hook 实现：
- 默认闪烁阈值 100ms（数据在 100ms 内加载完成则不显示骨架屏）
- 每视图覆盖：知识图谱 200ms（D3 初始化较慢）、设置 50ms（本地数据）
- 状态返回：`showSkeleton`, `isTimedOut`, `elapsedSeconds`, `reset`

### 5.4.3 — 超时状态（>10s）

**文件**: `src/components/ui/loading-timeout.tsx`, `src/components/skeleton/view-loading.tsx`

- 10 秒超时后替换骨架屏为超时提示
- 每视图定制标题和描述文案
- "Try Again" 和 "Cancel" 操作按钮
- 实时已用时间计数器

### 5.4.4 — 首次启动动画

**文件**: `src/components/ui/launch-loader.tsx`

- 4 步加载动画（数据库初始化 → 知识库加载 → Agent 运行时 → 准备完成）
- 进度条 + 文字提示
- 集成到 `src/app/(main)/layout.tsx`，首次启动时显示

### 页面集成

以下页面已集成 `ViewLoadingState` 包装器：
- Inbox（收件箱）
- Research（研究仪表盘）
- Domain/Knowledge（知识列表）
- Framework（框架分析）
- Timeline（时间线）

### CSS 支持

在 `globals.css` 中添加：
- 骨架屏布局样式（所有 9 个视图）
- 超时状态 UI 样式
- 首次启动加载器样式和动画
- fadeIn 过渡动画
- `prefers-reduced-motion` 降级处理
