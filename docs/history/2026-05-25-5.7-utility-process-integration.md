# 5.7 Utility Process 集成

> 日期：2026-05-25
> 任务：5.7 Utility Process 集成（5.7.1 ~ 5.7.5）
> 依赖：P0.3（Worker 架构规格）、Phase 3-4

## 目标

将 CPU 密集型操作（embedding 生成、图谱布局计算、PDF 文本抽取）移入 Electron Utility Process，避免阻塞主进程 UI 线程。实现带优先级的任务队列、进度报告和取消机制。

## 实现摘要

### 新增文件

| 文件 | 职责 |
|---|---|
| `server/worker/types.ts` | 消息协议（Main ↔ Worker）、7 种任务类型、payload/result 接口、错误类 |
| `server/worker/task-queue.ts` | 优先级队列（HIGH/NORMAL/LOW，FIFO，最大 100 任务）+ 限流进度报告器 |
| `server/worker/worker-process.ts` | Utility Process 入口：MessagePort 初始化、任务分发、内存监控、超时/取消 |
| `server/worker/worker-bridge.ts` | 主进程桥接：WorkerBridge 类（初始化/提交/取消/关闭）、单例管理、指数退避重启 |
| `server/worker/tasks/embedding-task.ts` | EMBEDDING_GENERATION + BATCH_EMBEDDINGS 处理器（hash-based 离线嵌入） |
| `server/worker/tasks/vector-index-task.ts` | VECTOR_INDEX_BUILD 处理器（批量嵌入生成 + 向量返回） |
| `server/worker/tasks/graph-layout-task.ts` | GRAPH_LAYOUT_COMPUTE 处理器（力导向布局 + 收敛检测 + circular/grid 降级） |
| `server/worker/tasks/pdf-parse-task.ts` | PDF_TEXT_EXTRACT 处理器（pdf-parse 库，50MB 文件限制，500 页限制） |

### 架构关键决策

1. **单 Utility Process + 内部队列**：30-50MB 固定内存，低复杂度，适合个人应用
2. **MessagePort 双向通信**：通过 `MessageChannelMain` 创建 port pair，worker 端接收 port 进行通信
3. **顺序执行**：一次只执行一个任务，避免内存膨胀
4. **优雅降级**：所有服务在 Worker 不可用时自动回退到主进程直接执行
5. **内存监控**：Worker 进程每 5 秒检查内存，90% 暂停队列，100% 中止当前任务
6. **重启策略**：指数退避重启（最大 30s 延迟），最多 5 次尝试
