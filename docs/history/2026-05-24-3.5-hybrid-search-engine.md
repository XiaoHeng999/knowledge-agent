# 3.5 混合搜索引擎

## 目标

实现混合搜索引擎，结合向量语义搜索和 BM25 全文搜索，通过 Reciprocal Rank Fusion (RRF) 融合排序，提供统一的知识搜索能力。

## 实现摘要

### 服务端

1. **SearchEngine 服务** (`server/services/search-engine.ts`)
   - 编排向量搜索 + BM25 全文搜索 + RRF 融合排序
   - 支持领域过滤、分页、日期/标签/来源筛选
   - 提供 `search`、`indexNode`、`removeFromIndex`、`reindexDomain` 接口
   - 批量加载节点数据（分块查询避免 SQL 变量限制）

2. **Embedding 服务** (`server/services/embedding-service.ts`)
   - 可插拔的 EmbeddingProvider 策略模式
   - 默认使用确定性哈希嵌入（离线可用）
   - 1536 维向量，L2 归一化
   - 支持运行时切换为 API 嵌入服务

3. **向量索引管道** — 知识节点创建/更新/删除时自动触发嵌入生成和向量索引更新
   - 修改 `knowledge-graph.ts` 中的 `createNode`、`updateNode`、`deleteNode`
   - 使用 fire-and-forget 异步模式，不阻塞 CRUD 操作

4. **BM25 全文搜索** — 利用已有的 FTS5 虚拟表 `fts_knowledge`（含 porter 分词器 + INSERT/DELETE/UPDATE 触发器）

5. **RRF 融合排序** — 使用 `VectorIndex.hybridSearch()` 方法，k=60，合并向量 + BM25 结果

### IPC 层

- 新增 `SEARCH_CHANNELS`：`search:search`、`search:reindexDomain`
- 新增 `server/ipc/handlers/search-handler.ts`
- 更新 `knowledge:search` 处理器委托给 SearchEngine
- 更新 `electron/preload.ts` 暴露 `search.search`、`search.reindexDomain`

### 前端

- **SearchBar** (`src/components/search/search-bar.tsx`)：搜索输入 + 防抖 + 下拉结果
- **SearchResults** (`src/components/search/search-results.tsx`)：结果列表 + 匹配高亮 + 类型徽标（Semantic/Text/Hybrid）
- 更新侧边栏使用 SearchBar 组件替代原有静态搜索输入
- 新增搜索相关 CSS 样式（输入框、下拉、高亮、徽标）
