# 2.3 安全版本控制 — 实现记录

**日期**: 2026-05-23
**任务**: Phase 2, Task 2.3 — 安全版本控制
**提交**: `feat: implement secure version control (2.3)`

## 目标

实现基于 Git 的版本控制系统，支持自动提交、Diff 可视化、版本历史浏览、一键回滚，以及 Agent 写入范围限制。

## 实现摘要

### 2.3.1 VersionControl 服务 (`server/services/version-control.ts`)
- `initRepo()` — 在数据目录自动初始化 Git 仓库，创建 `.gitignore`，执行首次提交
- `autoCommit()` — 指定文件 `git add + commit`，生成带描述的提交消息
- `getHistory()` — 获取文件的 Git 提交历史（`git log`）
- `getDiff()` — 生成两个 commit 之间的统一格式 diff
- `rollbackFile()` — 回滚文件到指定版本（pre-rollback commit + restore + post-rollback commit）
- `getStatus()` — 获取仓库状态（初始化状态、分支、未提交变更数）
- 内置统一 diff 解析器，解析 `@@ -a,b +c,d @@` 格式的 hunks 和行级变更

### 2.3.2 Pre-write 自动 Commit 钩子
- `preWriteCommit()` — Agent 写入操作前自动触发 `git add + commit`
- 生成格式化提交消息：`${operation}: ${relativePath} in ${domainSlug}`
- 无变更时静默处理（不报错）

### 2.3.3 Diff 可视化组件 (`src/components/diff/diff-viewer.tsx`)
- 解析 `FileDiff[]` 结构，按文件分块显示
- 颜色编码：绿色=新增、红色=删除、无高亮=上下文
- 显示行号（旧/新）和前缀标记（+/-/空格）
- 无变更时显示 "No changes between selected versions"

### 2.3.4 + 2.3.5 版本历史面板 + 一键回滚 (`src/components/diff/version-history.tsx`)
- 提交列表展示（短 hash + 消息 + 作者 + 相对时间）
- 两步选择两个 commit 进行 diff 比较
- 一键回滚：点击 "Restore" → 确认对话框 → 执行回滚 → 刷新列表
- 加载态、错误态、空态完整处理

### 2.3.6 写入范围限制 (`server/services/security-gate.ts`)
- 4 级风险评估：LOW（自动通过）、MEDIUM（需确认）、HIGH（需明确批准）、BLOCKED（永远拒绝）
- 路径边界检查：Agent 只能写入指定领域目录
- 文件类型检查：阻止可执行文件写入
- 待审核队列管理（内存存储，按风险级别排序）
- 审计日志记录

### IPC 层
- 新增 `VC_CHANNELS`（5 个通道）和 `SECURITY_CHANNELS`（5 个通道）
- 完整的 TypeScript 类型定义（`IpcChannelMap` 扩展）
- Preload bridge 暴露 `window.api.vc.*` 和 `window.api.security.*`
- IPC handlers 注册 + unregisterAll 更新
