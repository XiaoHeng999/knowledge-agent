## 目标

## 实现摘要

### P0.4 主题 Token 系统（4 子任务 → 3 个文件）

| 文件 | 内容 |
|------|------|
| `specs/theme-system/token-definitions.md` | 33 个规范 Token 定义（16 颜色 + 5 间距 + 4 圆角 + 3 阴影 + 5 排版），包含 CSS 变量命名规则和使用约束 |
| `specs/theme-system/style-pack-mappings.md` | 5 种风格包完整映射值：Tokyo Night（默认）、Linear、Cursor、Notion、PostHog，每种含全部 33 Token 的具体 CSS 值 |
| `specs/theme-system/runtime-switching.md` | 运行时切换架构：CSS 变量原子替换、useTheme Hook 接口、3 个入口（Settings/Cmd+T/Sidebar）、持久化策略、FOWT 防护 |

### P0.5 数据库迁移系统（3 子任务 → 3 个文件）

| 文件 | 内容 |
|------|------|
| `specs/database-layer/migration-format.md` | 迁移文件格式：TypeScript 模块接口、命名规范（NNN_name.ts）、事务策略、幂等性要求 |
| `specs/database-layer/migration-runner.md` | MigrationRunner 类设计：pending 检测、顺序执行、事务隔离、回滚策略（含备份）、4 层验证 |
| `specs/database-layer/initial-schema.md` | 初始迁移脚本：15 张物理表 + 3 张虚拟表（vss_nodes、fts_knowledge、schema_migrations）的完整 CREATE TABLE 语句，含索引、约束、触发器、默认设置种子 |

### P0.6 首次运行引导流程（3 子任务 → 3 个文件）

| 文件 | 内容 |
|------|------|
| `specs/onboarding/onboarding-flow.md` | 4 步引导流程线框图：欢迎屏 → API Key 设置（3 路径） → 创建首个领域 → 引导研究 Tour（5 个 Spotlight） |
| `specs/onboarding/empty-states.md` | 7 个空状态场景设计：空收件箱、空领域、空时间线、空研究仪表盘、空专家对话、无 API Key（全屏阻塞）、空知识列表，含统一 EmptyState 组件接口 |
| `specs/onboarding/domain-templates.md` | 5 个领域预设模板：AI/ML、Web Development、Product & Design、Business Strategy、Custom，每个含完整 config.yaml 模板（sources、research、frameworks、tags、skills） |
