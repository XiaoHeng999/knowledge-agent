# 5.8 跨平台构建 — 实现记录

**日期**: 2026-05-25
**阶段**: Phase 5.8
**状态**: 已完成

## 目标

完成 AgentClaw 的跨平台构建配置，包括 macOS/Windows/Linux 三平台打包、路径抽象验证、自动更新和 CI/CD 矩阵构建。

## 实现摘要

### 5.8.1 macOS 构建
- 更新 `electron-builder.yml`：DMG (arm64 + x64)、hardenedRuntime、entitlements、notarization 配置
- 创建 `resources/entitlements.mac.plist`（JIT、网络、文件访问权限）

### 5.8.2 Windows 构建
- 配置 NSIS 安装器（自定义安装路径、桌面/开始菜单快捷方式）
- 配置 Portable 版本
- 统一 artifact 命名格式

### 5.8.3 Linux 构建
- 配置 AppImage + deb + rpm（x64）
- deb 依赖声明（libnotify4, libxtst6, libnss3）
- 统一 artifact 命名格式

### 5.8.4 路径抽象层验证
- `server/fs/paths.ts` 已使用 `app.getPath('userData')` + `path.join()` — 三平台路径正确
- `server/fs/provider.ts` (FileSystemProvider) 使用 `path.join()` 和 `path.dirname()` — 跨平台兼容
- 新增 `src/lib/platform.ts`：渲染进程平台检测工具（修饰键判断、平台缓存）

### 5.8.5 自动更新
- 安装 `electron-updater` 依赖
- 新增 `server/services/auto-updater.ts`：检查/下载/安装生命周期管理
  - 启动时检查 + 每 4 小时定期检查
  - macOS/Windows：自动下载 + 提示重启
  - Linux：提示手动下载（GitHub Release 链接）
- 新增 IPC 通道：`update:check`、`update:download`、`update:install`、`update:getStatus`
- 新增 `src/components/update/update-notification.tsx`：更新通知 UI
- 主进程集成（main.ts 初始化 + 关闭清理）
- preload.ts 暴露 update API

### 5.8.6 CI/CD 矩阵构建
- 新增 `.github/workflows/build.yml`
  - lint + typecheck 前置检查
  - macOS/Windows/Linux 三平台矩阵构建
  - 标签推送自动发布 GitHub Release
  - 代码签名环境变量配置（secrets）
- 新增构建脚本：`build:mac`、`build:win`、`build:linux`、`build:all`
