# 3.7 Diff 审核与安全关卡

> 日期: 2026-05-24
> 阶段: Phase 3 — Agent 协作层
> 关联任务: 3.7.1 ~ 3.7.4

## 目标

实现 Agent 写入操作的安全审核机制：在 Agent 修改知识库内容时，通过 Diff 可视化、审核队列和风险分级审批确保用户对写入操作保持完全控制。

## 实现摘要

### 3.7.1 Diff 生成服务

- 新建 `server/services/diff-service.ts`
- 纯内存行级 diff 算法（基于 LCS — Longest Common Subsequence）
- 支持 diff 结果分块（hunks）、统计（added/removed/unchanged）
- 提供 `generateUnifiedPreview` 用于预览截断显示
- 新增 IPC 通道 `security:generateDiff`，preload 桥接和 handler 全链路打通

### 3.7.2 Diff 审核队列

- 新建 `src/stores/security-store.ts` — Zustand store 管理待审核队列状态
- 新建 `src/components/security/diff-review-card.tsx` — 单个 diff 审核卡片（操作类型、文件名、风险等级、diff 预览）
- 新建 `src/components/security/diff-review-stack.tsx` — 右侧面板堆栈排队（HIGH → MEDIUM → LOW 排序），批量操作按钮
- 新建 `src/components/security/pending-badge.tsx` — 聊天输入区"X pending"徽标，点击打开右侧面板
- 新建 `src/lib/hooks/use-security-gate.ts` — 封装安全网关 IPC 调用 + 轮询 hook
- 集成到 `message-input.tsx`，输入区域自动显示待审核徽标
- 更新 `layout-context.tsx` 新增 `diff-review` 面板类型（默认 420px）

### 3.7.3 Diff 审核交互

- 新建 `src/components/security/edit-and-apply.tsx` — MEDIUM 风险操作的编辑后应用模式（textarea 编辑器 + Apply/Cancel）
- 新建 `src/components/security/approve-confirm.tsx` — HIGH 风险操作的确认对话框（需输入 "APPROVE" 才能确认）
- DiffReviewCard 内置交互状态切换：卡片 ↔ 编辑模式 ↔ 确认模式

### 3.7.4 写入权限检查

- 改造 `server/ipc/handlers/knowledge-handler.ts` — create/update/delete 操作经过 `assessWriteRisk` 风险评估
- LOW 风险自动通过并记录审计日志
- MEDIUM/HIGH 风险进入待审核队列，返回 `{ _pendingAudit, risk }`
- BLOCKED 操作直接拒绝并抛出错误
- 更新 `security-handler.ts` 审计日志记录
