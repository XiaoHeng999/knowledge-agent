# 1.6 pi-mono SDK 集成

> **日期**: 2026-05-23
> **阶段**: Phase 1 - 基础骨架
> **状态**: 已完成
> **提交**: `44c999b feat: implement pi-mono SDK integration (1.6)`

## 目标

将 pi-mono SDK (`@mariozechner/pi-coding-agent`) 集成到 AgentClaw 中，为后续的模型管理、专家对话、定时研究等功能提供 AI Agent 基础设施。

## 实现摘要

### 1.6.1 核心初始化 (`server/pi-mono/core.ts`)
- `PiMonoCore` 类：管理 AuthStorage、ModelRegistry、SessionManager、DefaultResourceLoader 的生命周期
- 支持配置化的 userDataPath 和自定义扩展工厂
- 提供 API Key 管理方法（设置/删除/查询认证状态）

### 1.6.2 Provider 注册 (`server/pi-mono/providers.ts`)
- 注册 9 个 LLM Provider：Anthropic、OpenAI、DeepSeek、Google、Groq、Ollama、OpenRouter、xAI、Mistral
- 每个 Provider 包含默认 base URL、API 协议和模型列表（含成本、上下文窗口等元数据）
- 未配置 API Key 的 Provider 标记为不可用

### 1.6.3-5 自定义工具 (`server/pi-mono/tools/`)
- `domain_research`：领域知识搜索与综合工具，支持 quick/deep 两种深度
- `knowledge_write`：知识节点写入工具，支持 7 种节点类型和标签系统
- `timeline_analyze`：时间线分析与预测工具，支持月/季度/年度范围
- 所有工具使用 TypeBox 定义参数 Schema，支持可插拔的 Executor 模式

### 1.6.6 扩展加载 (`server/pi-mono/extensions/`)
- `knowledgeToolsExtension`：注册知识管理工具（domain_research + knowledge_write）
- `researchAgentExtension`：注册研究代理工具（timeline_analyze）+ 生命周期钩子
- `importAgentExtension`：预留导入处理扩展（Phase 4 完整实现）

### 1.6.7 封装层接口 (`server/services/pi-mono-wrapper.ts`)
- 6 大核心接口抽象：IModelManager、IAgentPool、IKnowledgeDB、ISkillEngine、IImportPipe、ISearchEngine
- `PiMonoWrapper` 类实现了 IModelManager 和 IAgentPool
- IKnowledgeDB/ISkillEngine/IImportPipe/ISearchEngine 接口定义完成，等待后续 Phase 实现

## 技术决策

1. **Executor 模式**：自定义工具使用可插拔的 Executor 函数，避免工具代码直接依赖数据库层，保持解耦
2. **封装层设计**：6 大接口将 pi-mono API 与 AgentClaw 业务逻辑隔离，降低 SDK API 变更的影响
3. **Provider 配置**：所有 Provider 元数据集中定义，便于后续添加新 Provider
