# 1.1 项目初始化

**日期**: 2026-05-23
**阶段**: Phase 1 — 基础骨架
**任务**: 1.1 项目初始化 (1.1.1 ~ 1.1.5)

## 目标

搭建 Electron + Next.js 15 项目脚手架，建立基础目录结构和开发工具链，使 `npm run dev` 能启动 Electron 窗口并显示 Next.js 渲染的页面。

## 实现摘要

### 1.1.1 Monorepo 结构
- 创建 `package.json`（依赖：Electron 33, Next.js 15, React 19, Zustand 5, better-sqlite3）
- 创建根 `tsconfig.json`（ES2022, JSX preserve, bundler module resolution, path aliases）
- 创建 `electron/tsconfig.json`（CommonJS 输出到 `dist/electron/`）
- 配置 ESLint flat config（`eslint.config.mjs`）
- 更新 `.gitignore`（增加 `release/` 目录）

### 1.1.2 Electron 主进程
- `electron/main.ts`：单实例锁、窗口创建、生命周期管理、全局快捷键清理
- `electron/window.ts`：BrowserWindow 配置（无边框、1024x768 最小尺寸、安全 webPreferences）
- `electron/preload.ts`：contextBridge 暴露 `window.api`，类型安全的 IPC 调用
- `electron/ipc-register.ts`：IPC handler 注册入口
- `src/types/electron.d.ts`：Window.api 类型声明

### 1.1.3 Next.js 15 前端
- `next.config.ts`：static export 模式、Turbopack、unoptimized images
- `src/app/layout.tsx`：根布局
- `src/app/page.tsx`：首页占位
- `src/app/globals.css`：30+ CSS Token 变量（Tokyo Night 暗色主题基座）

### 1.1.4 electron-builder 配置
- 三平台构建：macOS DMG (arm64+x64)、Windows NSIS+Portable (x64)、Linux AppImage+deb+rpm (x64)

### 1.1.5 开发工具链
- `dev` 脚本：concurrently 并发运行 Next.js dev server + Electron
- TypeScript path aliases：`@/*`, `@electron/*`, `@server/*`
- 验证：`npm run build` 成功输出 `out/` 静态文件和 `dist/electron/` 编译结果

## 修复的问题

1. **electron/tsconfig.json rootDir 错误**：从 `..` 改为 `.`，避免输出路径嵌套为 `dist/electron/electron/`
2. **缺少 @eslint/eslintrc 依赖**：添加到 devDependencies
3. **根 tsconfig 缺少 jsx 选项**：添加 `"jsx": "preserve"`
4. **移除未使用的 electron-is-dev**：改用 `app.isPackaged`

## 验证结果

- `npx tsc -p electron/tsconfig.json` ✓ 通过
- `npx tsc --noEmit -p tsconfig.json` ✓ 通过
- `npx next build` ✓ 成功导出静态文件到 `out/`
- Electron 编译输出到 `dist/electron/main.js` ✓ 路径正确
