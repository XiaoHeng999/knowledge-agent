# 1.3 三栏布局框架 — 实现记录

> 日期：2026-05-23
> 任务：Phase 1 → 1.3 三栏布局框架
> 状态：已完成

## 目标

实现 AgentClaw 应用的三栏自适应布局框架，包括标题栏、侧边栏、主内容区、右侧详情面板和状态栏。

## 实现摘要

### 新建文件

| 文件 | 描述 |
|------|------|
| `src/components/layout/layout-context.tsx` | 布局状态上下文（侧边栏折叠、面板开关/宽度/内容类型、视口断点检测） |
| `src/components/layout/titlebar.tsx` | 36px 自定义标题栏（汉堡菜单、领域色点、应用名、Cmd+K 提示、窗口控制按钮） |
| `src/components/layout/statusbar.tsx` | 28px 状态栏（模型名、费用、研究状态） |
| `src/components/layout/sidebar.tsx` | 侧边栏（搜索输入、领域导航列表、快速记录按钮、设置入口、折叠模式） |
| `src/components/layout/detail-panel.tsx` | 右侧面板（拖拽调整宽度、内容类型标题、关闭按钮、覆盖层模式、Escape 关闭） |
| `src/app/(main)/layout.tsx` | 主布局路由组（三栏布局组装） |
| `src/app/(main)/page.tsx` | 首页占位内容 |

### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/app/globals.css` | 新增 spacing/shadow/layout CSS 变量，所有布局组件 CSS，响应式断点 |
| `src/lib/ipc/channels.ts` | 新增 WINDOW_CHANNELS（minimize/maximize/close/isMaximized/toggleMaximize） |
| `electron/preload.ts` | 新增 `window` 命名空间 API |
| `server/ipc/register.ts` | 新增窗口控制 IPC handler 注册 |
| `server/ipc/handler.ts` | 新增窗口通道的注销条目 |

### 删除文件

| 文件 | 原因 |
|------|------|
| `src/app/page.tsx` | 移入 `(main)` 路由组，避免路由冲突 |

## 响应式断点

| 视口宽度 | 侧边栏 | 右侧面板 |
|----------|--------|----------|
| < 900px | 折叠（48px 图标模式） | 覆盖层（40vw, min 280px） |
| 900-1200px | 180px | 正常（最大 400px） |
| > 1200px | 240px | 正常（最大 400px） |
