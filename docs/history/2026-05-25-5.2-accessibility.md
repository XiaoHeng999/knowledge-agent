# 5.2 无障碍完善 — 实现记录

**日期**: 2026-05-25
**阶段**: Phase 5.2
**状态**: 已完成

## 目标

完成 AgentClaw 应用的无障碍（Accessibility）完善，覆盖 ARIA 属性、焦点管理、键盘导航、动画降级、颜色对比度验证和最小触控目标六个方面。

## 实现摘要

### 5.2.1 ARIA 属性

为所有自定义组件添加了完整的 ARIA 属性：

- **Toast**: 使用 `role="status"` + 基于 type 的 `aria-live`（error=assertive, 其他=polite）+ `aria-atomic`
- **Knowledge Card**: 添加 `aria-label` 包含标题和类型信息，类型徽标添加 `aria-label`
- **Domain List**: 添加 `role="tree"` 容器 + `role="treeitem"` 项 + `aria-selected` + `aria-hidden` 装饰性圆点
- **Segmented Control**: 添加 `aria-label="View mode"` 到 radiogroup
- **Graph View**: 图谱画布添加 `role="img"` + 描述性 `aria-label`，SVG 标记 `aria-hidden`
- **Skeleton**: 包装器添加 `role="status"` + `aria-label="Loading content"`
- **Statusbar**: 添加 `role="contentinfo"` + `aria-label="Application status"`
- **Titlebar**: 添加 `role="banner"` + 装饰性圆点 `aria-hidden`
- **Tooltip**: 通过 `aria-describedby` 连接触发器和提示框
- **Detail Panel**: SVG 图标标记 `aria-hidden`

### 5.2.2 焦点管理

- 创建 `useFocusTrap` hook — Tab 键焦点在容器内循环
- 创建 `useFocusTransfer` hook — 打开时保存焦点、关闭时恢复
- 创建 `useRouteFocus` hook — 路由切换时焦点移至主标题
- **Dialog** 组件重构为使用共享 hook（替代内联实现）
- **DetailPanel** 添加打开时聚焦关闭按钮 + 关闭时恢复焦点
- 全局 `:focus-visible` 样式（2px solid accent 环）

### 5.2.3 键盘导航

- 添加 **Skip-to-content** 链接（首个 Tab 可见）
- `<main>` 元素添加 `id="main-content"` + `tabIndex={-1}`
- 路由切换时自动聚焦到页面标题

### 5.2.4 prefers-reduced-motion

- 聊天自动滚动尊重 `prefers-reduced-motion`（reduced → `behavior: 'auto'`）
- 全局 CSS 已覆盖 `animation-duration: 0.01ms` + `transition-duration: 0.01ms`

### 5.2.5 颜色对比度验证

- 创建 `scripts/validate-contrast.ts` 构建时验证脚本
- 修复 **5 个风格包** 的对比度问题：
  - Tokyo Night: `--text-secondary` #565f89 → #8289ac
  - Cursor: `--text-secondary` #6c7086 → #9398ad
  - Notion: `--text-secondary` #787774 → #6d6c69, `--accent` #2eaadc → #1e8ab8, `--warning` #dfab01 → #b88000
  - Linear: `--warning` #e5973e → #c47e28
- **45/45 对比度检查全部通过**（装饰性 text-tertiary 和 border 除外）

### 5.2.6 最小触控目标

- 全局 CSS 规则确保按钮/链接 ≥ 32x32px
- 修复 titlebar 控件 28px → 32px
- 修复 detail-panel 关闭按钮和 toast 关闭按钮（添加 padding 扩展点击区域至 32px）
