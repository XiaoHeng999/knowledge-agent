### CSS 样式

所有组件样式追加到 `src/app/globals.css`，使用 BEM 命名 (`ui-` 前缀)。样式严格引用 30 个 CSS Token：
- 颜色: `--bg-primary`, `--bg-secondary`, `--bg-tertiary`, `--surface`, `--text-primary/secondary/tertiary`, `--accent`, `--error`, `--warning`, `--success`, `--info`
- 间距: `--spacing-xs/sm/md/lg/xl`
- 圆角: `--radius-sm/md/lg/full`
- 阴影: `--shadow-sm/md/lg`
- 排版: `--font-sans/mono`, `--font-size-sm/base/lg`
- 过渡: `--transition-fast/normal`

### 动画

- `skeleton-pulse`: 骨架屏闪烁 (1.5s ease-in-out infinite)
- `toast-enter`: Toast 从右下角滑入 (300ms cubic-bezier)
- `spin`: 加载旋转
- `progress-indeterminate`: 不确定进度条滑动
- `fade-in`: 通用淡入 (100-150ms)
- `dialog-enter`: 对话框缩放进入 (200ms)
- 全局 `prefers-reduced-motion: reduce` 覆盖

### Barrels

`src/components/ui/index.ts` 导出所有 12 个组件，支持 `import { Button, Input } from '@/components/ui'` 用法。
