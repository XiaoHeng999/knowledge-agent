# 4.1 定时研究代理（F2）— 开发记录

**日期**: 2026-05-24
**任务**: 实现 Phase 4.1 — 定时研究代理（F2 Scheduled Research Agent）

## 目标

实现定时研究代理功能，包括 cron 调度、pi-mono Agent 执行研究、结果自动创建知识节点、研究仪表盘 UI。

## 实现摘要

### 服务端

1. **ResearchRunsRepository** (`server/db/repositories/research-runs.ts`)
   - 基于 BaseRepository 的 research_runs 表数据访问
   - 支持按领域筛选、统计每日运行次数、按日期范围汇总成本

2. **ResearchScheduler 服务** (`server/services/research-scheduler.ts`)
   - Cron 表达式解析器（5 字段标准 cron）
   - 每分钟 tick 检查所有领域调度
   - 研究执行器：使用 pi-mono AgentSession + 廉价模型（优先 DeepSeek/Groq/Ollama）
   - 结果处理：研究输出 → 自动创建知识节点（直接入库）
   - 成本追踪：按模型定价估算 token 成本，检查每日预算
   - 研究提示构建：从领域 config.yaml 的 queryTemplates + tags 生成研究提示

3. **Research IPC Handler** (`server/ipc/handlers/research-handler.ts`)
   - 5 个通道：trigger / getStatus / listHistory / getDashboard / cancel
   - 注册到 IPC register.ts，移除 TODO 占位

4. **Electron 主进程集成**
   - `electron/main.ts` 中启动/停止 scheduler
   - DB index 中添加 ResearchRunsRepository

### 前端

5. **Research Store** (`src/stores/research-store.ts`)
   - Zustand store：dashboard 数据、历史列表、活跃运行、触发/取消操作

6. **研究仪表盘页面** (`src/app/(main)/research/page.tsx`)
   - 每日摘要、领域选择 + 手动触发按钮、进度显示
   - 成本追踪卡片（总额 + 按模型分布）
   - 研究历史时间线（状态圆点 + 时间 + 域名 + 状态标签）
   - 自动轮询活跃运行状态（3s 间隔）

7. **侧边栏导航**
   - 添加 Research 入口按钮

### 样式

8. **Research 页面 CSS** — 在 globals.css 中添加完整 BEM 样式
   - 触发区域、成本卡片网格、时间线（含状态动画）
   - 遵循项目现有 CSS 变量体系
