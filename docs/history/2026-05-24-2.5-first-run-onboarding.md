# 2.5 首次运行引导流程

> 日期: 2026-05-24
> 任务: 2.5.1 ~ 2.5.6

## 目标

实现 AgentClaw 的首次运行引导流程，包括 4 步引导（欢迎屏 → API Key 设置 → 创建首个领域 → 引导研究），以及无 API Key 时的全屏阻塞状态。

## 实现摘要

### 2.5.1 引导流程控制器 (`src/stores/onboarding-store.ts`)
- 基于 Zustand + persist 中间件的引导步骤状态管理
- 4 步流程: welcome → api-key → create-domain → guided-tour
- 支持 start/nextStep/prevStep/skip/complete/completeTour 操作
- 持久化 completed、tourCompleted、hasApiKey 状态到 localStorage

### 2.5.2 欢迎屏 (`src/components/onboarding/welcome-screen.tsx`)
- AgentClaw 品牌展示: 名称 + tagline + 4 个功能亮点
- "Get Started" 主按钮 + "Skip" 跳过链接

### 2.5.3 API Key 设置引导 (`src/components/onboarding/api-key-setup.tsx`)
- 3 种连接方式: Configure API Key / Free Trial / Local (Ollama)
- API Key 模式: Provider 选择 + Key 输入 + 连接测试验证
- Ollama 模式: 自动检测 localhost:11434 + 列出可用模型
- Free Trial 模式: 共享代理说明

### 2.5.4 创建首个领域引导 (`src/components/onboarding/create-first-domain.tsx`)
- 5 个预设模板: AI/ML、Web Development、Product & Design、Business Strategy、Custom
- 模板卡片 3 列网格布局，选中高亮
- 支持自定义域名输入
- 通过 IPC 调用 domain.create 创建领域

### 2.5.5 引导研究步骤 (`src/components/onboarding/guided-research.tsx`)
- 完成引导后的庆祝界面
- "Take Tour" / "Skip Tour" 两个选项
- 列出 5 个游览亮点

### 2.5.6 无 API Key 阻塞状态 (`src/components/onboarding/no-api-key-blocker.tsx`)
- 全屏引导卡片（非常规空状态）
- 3 种解决路径: API Key / Free Trial / Ollama
- 可展开的 API Key 配置子视图
- "limited mode" 浏览选项

### 集成
- `OnboardingOverlay` 组件整合 4 步流程 + 步骤指示器
- 集成到 `(main)/layout.tsx`，首次启动自动弹出
- 所有样式通过 CSS BEM 命名添加到 globals.css
