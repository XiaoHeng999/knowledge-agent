# 3.3 专家对话（主动模式）实现记录

> 日期: 2026-05-24
> 任务: Phase 3.3 — 专家对话（F5 主动模式）
> 状态: 已完成

## 目标

实现基于 pi-mono Agent 的专家对话功能，包括会话管理、流式响应、树状会话分支、领域上下文自动加载。

## 实现摘要

### 后端

1. **数据库层**
   - 新增 `server/db/repositories/conversations.ts` — 对话表 CRUD，含按领域筛选、按会话类型查询
   - 新增 `server/db/repositories/messages.ts` — 消息表 CRUD，含树结构查询（子节点列表、分支索引、根消息、递归 CTE 获取活跃分支）
   - 注册到 `DatabaseService` 接口

2. **服务层**
   - 新增 `server/services/conversation-service.ts` — 核心对话服务
     - 对话 CRUD（创建、列表、获取、删除）
     - 消息管理（添加消息、分支消息）
     - 领域上下文自动加载（最近 20 个知识节点 + 5 条决策记录）
     - 流式响应（通过 pi-mono AgentSession 的 `prompt()` + `subscribe()` 模式）
     - 流中止（AbortController）

3. **IPC 层**
   - 新增 `CHAT_CHANNELS` 9 个通道定义（createConversation, listConversations, getConversation, deleteConversation, getTree, sendMessage, abortStream, addMessage, branchFromMessage）
   - 新增 `server/ipc/handlers/chat-handler.ts` — 全部 9 个 handler
   - 注册到 `register.ts`
   - 扩展 `electron/preload.ts` 添加 `chat` API 命名空间

### 前端

1. **状态管理**
   - 新增 `src/stores/chat-store.ts` — Zustand store
     - 对话列表、当前对话、消息树
     - 流式状态（streaming, streamingContent, streamingMessageId）
     - 分支导航（activeBranchPaths）
     - 折叠状态（collapsedNodeIds）

2. **UI 组件**
   - `src/app/(main)/domain/[id]/chat/page.tsx` — 对话页面容器，包含模型选择、对话列表、输入区
   - `src/components/chat/message-list.tsx` — 扁平消息列表，含 Markdown 渲染 + 流式指示
   - `src/components/chat/message-input.tsx` — 多行输入 + 发送/中止按钮
   - `src/components/chat/conversation-tree.tsx` — 树状会话组件
     - 树构建算法（parent_id + branch_index → 嵌套树）
     - 分支选择器（BranchSelector, ◄ N/M ►）
     - 折叠/展开（带隐藏消息计数）
     - 虚拟滚动 hook（> 50 条消息激活）
     - "New Branch" 按钮（从用户消息创建同级分支）

3. **样式**
   - globals.css 新增 ~250 行对话相关样式
