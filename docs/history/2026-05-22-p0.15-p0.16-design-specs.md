## 目标

完成 Phase 0 最后两项设计规格任务，为编码阶段提供精确的组件实现规格。

## 实现摘要

### P0.15 组件精确规格升级 (DT12)

**产出文件**: `openspec/changes/agentclaw-implementation/specs/design-specs/component-specs.md`

- **P0.15.1**: 为 28 个组件库中每个组件创建了精确规格表
  - 定义了 12 级排版级别系统（stat → badge），映射到 5 个 canonical 字体 token
  - 12 个基础 UI 组件: Sidebar, ContextPanel, TreeView, CommandPalette, ModelSwitcher, ComprehensionIndicator, DiffViewer, StatusBadge, CostDisplay, Breadcrumb, SegmentedControl, ResizablePanel
  - 16 个业务组件: DomainOverview, KnowledgeGraph, KnowledgeList, KnowledgeNodeEditor, KnowledgeNodeDetail, Timeline, ExpertChat, ChatBranch, InboxList, InboxItem, ResearchDashboard, ModelManagement, ProviderCard, FrameworkAnalysis, DecisionRecord, SourceTracker
  - 每个组件包含: 构件解剖、排版级别、颜色 token 引用、间距 token、边框、阴影、交互状态（default/hover/active/focus/disabled）

- **P0.15.2**: 对齐风格包精度
  - 组件排版级别映射到 Linear 14 级排版系统
  - 5 种风格包字体大小差异表（Tokyo Night/Linear/Cursor/Notion/PostHog）
  - 所有颜色值引用 canonical token（无硬编码值）
  - Token 使用摘要（颜色/间距/圆角/阴影按组件分类）
  - 统一的状态设计模式（交互状态、选择状态、状态颜色）

### P0.16 其他设计规格

**P0.16.1** 领域理解分数可视化 (DT11)
- 产出: `specs/design-specs/comprehension-visualization.md`
- 理解度计算模型（加权平均）
- 4 种可视化组件: 进度环（仪表盘域卡片）、渐变条（领域概览页）、圆点行（知识节点卡片）、统计卡片
- SVG 结构定义、动画规格、无障碍属性、颜色对比度验证

**P0.16.2** 知识图谱导出/导入格式 (T9)
- 产出: `specs/knowledge-storage/graph-export-import-format.md`
- 完整 TypeScript 接口定义（7 个实体类型）
- 单文件 JSON (.agentclaw.json) + 大文件 ZIP 打包 (.agentclaw.zip)
- 导入流程: 解析 → 版本验证 → Schema 验证 → 冲突解决 → 数据写入 → 索引重建
- 4 种冲突解决策略: Merge (默认) / Overwrite / Keep Both / Skip
- UI 流程 + IPC API 定义

**P0.16.3** 高度断点 + 最小窗口规格 (DT14)
- 产出: `specs/design-specs/height-breakpoints.md`
- 最小窗口: 1024×768, 默认窗口: 1280×800
- 高度断点: Tall (≥900px) / Standard (768–899px)
- 侧边栏高度行为: <700px 视口时 Quick Record 隐藏，浮动按钮替代
- 8 个视图的最小内容高度
- Chat 紧凑模式 (<500px 内容高度)
- 全屏模式行为

**P0.16.4** 仪表盘焦点层级 (DT15)
- 产出: `specs/design-specs/dashboard-focus-hierarchy.md`
- 首行 60/40 分割: 今日概览 (60%) + 收件箱 (40%)
- 主统计: 48px/Bold(700) / -2.0px tracking
- 视觉权重层级: 统计 → 理解度环 → 收件箱徽标 → 域名 → 活动流
- 3 行布局: 统计行 → 域卡片 → 活动流
- 响应式断点（宽度 + 高度）
- 空状态设计
