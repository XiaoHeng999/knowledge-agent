# 3.2 知识图谱可视化

> 日期: 2026-05-24
> 阶段: Phase 3 — 3.2 知识图谱可视化（F10 部分）

## 目标

实现知识图谱的可视化展示，包括 D3.js 力导向图、WebGL 大规模降级、控制面板、视图切换和无障碍降级。

## 实现摘要

### 新增文件

| 文件 | 说明 |
|------|------|
| `src/components/graph/force-graph.tsx` | D3.js 力导向图核心组件：节点（颜色=领域色，大小=连接数）、边（粗细=权重）、缩放/平移、拖拽布局、tooltip |
| `src/components/graph/webgl-graph.tsx` | WebGL 降级组件：>1000 节点自动切换，内含轻量级力布局算法 |
| `src/components/graph/graph-controls.tsx` | 图谱控制面板：布局切换（力导向/分层/环形）、类型/理解度/领域筛选 |
| `src/components/graph/graph-view.tsx` | 图谱/列表视图切换容器，集成 SegmentedControl、自动 WebGL 检测、无障碍提示 |
| `src/app/(main)/domain/graph/page.tsx` | 图谱路由页面 |

### 修改文件

| 文件 | 说明 |
|------|------|
| `src/app/globals.css` | 新增 graph-view、force-graph、webgl-graph、graph-controls、graph-tooltip 样式 |
| `docs/file-map.md` | 新增 graph 组件目录和 graph 路由 |
