# 5.5 空状态完善

> 日期: 2026-05-25
> 任务: Phase 5.5 — Empty States Polish
> 对应规格: `specs/onboarding/empty-states.md`

## 目标

为 7 个视图实现符合设计规格的空状态：温暖感文案 + emoji 插图 + 主操作按钮 + 上下文说明。同时集成 NoApiKeyBlocker 到 AI 依赖视图。

## 实现摘要

### EmptyState 组件升级

- 新增 `emoji` 属性，支持 emoji 字符作为大尺寸装饰插图渲染
- 新增 `children` 属性，支持在操作按钮下方渲染额外内容（如推荐 prompt）
- globals.css 新增 `.ui-empty-state__emoji` 样式（48px）

### 7 个空状态视图

| 视图 | Emoji | 标题 | 主操作 | 次要操作 |
|------|-------|------|--------|----------|
| 收件箱 | 📥 | Your inbox is clear | Import your first source | or try a quick note ↓ |
| 知识列表 | 📚 | No knowledge nodes yet | Create knowledge node | — |
| 时间线 | 📅 | No events on the timeline | Run research to discover events | Timeline updates automatically → |
| 研究仪表盘 | 🔬 | No research runs yet | Run research now | or schedule first research → |
| 专家对话 | 💬 | Ask anything about this domain | 3 个推荐 starter prompts | — |
| 无 API Key | ⚠️ | AI features require an API key | NoApiKeyBlocker 全屏引导 | — |
| 仪表盘首页 | 🚀/🏠 | Welcome / Select a domain | Create your first domain | — |

### NoApiKeyBlocker 集成

- 专家对话页（`domain/[id]/chat/page.tsx`）：`hasApiKey === false` 时显示全屏 API Key 引导
- 研究仪表盘页（`research/page.tsx`）：同上
- 通过 `useOnboardingStore` 的 `hasApiKey` 状态判断

### 附加更新

- 图谱视图（`graph-view.tsx`）3 处空状态统一为 emoji 风格
- 时间线预测和趋势空状态也更新为 emoji + 操作按钮
